# 財務自由模擬器 Financial Independence Simulator

輸入年齡、生活開銷、投資計畫與報酬率，試算：

- **財務自由年份**：年度投資回報（投資總價值 × 年報酬率）第一次超過當年生活開銷的年份
- **退休後資產推估**：停止追加投資後，資產能否支撐到 90 歲
- **生涯目標**：把夢想與必要支出量化，合計後帶入每月生活開銷

純前端單頁，所有計算在瀏覽器內完成，輸入值只存在自己的瀏覽器（localStorage）。

## 計算方式

| 項目 | 公式 |
|---|---|
| 年度生活開銷 | 第 0 年 = 每月生活開銷 × 12；之後每年 × (1 + 通膨率) |
| 投資總價值 | 每期利率 = 年報酬率 ÷ 派息次數；每期期末投入 每月投資 × 12 ÷ 派息次數；逐期複利 |
| 財務自由判定 | 年度投資回報 > 年度生活開銷 的第一年 |
| 退休當年生活開銷 | 前一年 × (1 − 減少比例) × (1 + 通膨率)，之後逐年通膨 |
| 退休後剩餘資產 | 年初資產 + 年初資產 × 退休後報酬率 − 生活開銷（退休次年起） |

## 檔案

- `index.html`：頁面與互動
- `fire-core.js`：計算核心（可在 Node 以 `require` 使用）

> 本工具僅供個人理財規劃參考，不構成任何投資建議。
